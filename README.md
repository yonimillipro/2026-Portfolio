# Yonathan Million — Portfolio

An editorial portfolio for Yonathan Million, a frontend engineer, product builder, and IT Officer / Website Developer based in Addis Ababa, Ethiopia.

The site presents selected work including Dr. Saba Medium Clinic, Coinza Dashboard, Giveaway Fair, the private ServiceLink and GiveawayConnect products, and an earlier hotel reservation system. It also covers experience, practical capability areas, and a direct contact path. The interface is responsive, keyboard accessible, theme-aware, and built around real project evidence rather than skill percentages or placeholder case studies.

## Live portfolio

[https://2026-portfolio-lilac.vercel.app/](https://2026-portfolio-lilac.vercel.app/)

## Stack

- React 18 and TypeScript
- Vite
- GSAP + ScrollTrigger for scroll choreography and hover interactions
- Three.js for a lightweight, lazy-loaded hero scene
- Reduced-motion and mobile performance fallbacks
- Custom responsive CSS
- EmailJS contact form

## Local development

```bash
npm install
npm run dev
```

Quality checks:

```bash
npm run lint
npm run build
```
