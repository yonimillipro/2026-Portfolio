# Yonathan Million — Portfolio

An editorial portfolio for Yonathan Million, a software engineer and web, mobile, and desktop developer based in Addis Ababa, Ethiopia. He also works as an IT Officer / Website Developer at Dr. Saba Medium Clinic.

Selected work includes ClinicFlow, Giveaway Hub, Smart Timer for Windows, Dr. Saba Medium Clinic's website, Giveaway Fair, Coinza Dashboard, and an earlier academic hotel reservation system. Three expandable project stories explain the problem, approach, and current stage. The site also covers experience, web/mobile/desktop/API capabilities, the development process, and contact details.

ServiceLink Mobile — In development.

The interface is responsive, keyboard accessible, and theme-aware. The downloadable CV uses the same professional positioning and project stages. No private startup features, architecture, or screenshots are included.

## Stack

- React 18 and TypeScript
- Vite
- GSAP + ScrollTrigger for scroll choreography and hover interactions
- Three.js for a lightweight, lazy-loaded hero scene
- Reduced-motion and mobile performance fallbacks
- Custom responsive CSS
- EmailJS contact form

## Local development

```bash
npm install
npm run dev
```
